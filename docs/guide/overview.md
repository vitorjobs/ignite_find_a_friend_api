# Visão Geral

## API de Conexão entre Tutores e Pets

Esta é uma API RESTful para conectar tutores e pets, desenvolvida em Node.js com TypeScript. A aplicação segue boas práticas de desenvolvimento, utiliza validação de dados, versionamento de banco de dados com Prisma ORM e foi projetada para deploy tanto com Docker quanto em ambiente local.

## Arquitetura

- **Backend**: Node.js com TypeScript
- **Banco de Dados**: PostgreSQL com Prisma ORM
- **Monitoramento**: Prometheus e Grafana
- **Containerização**: Docker e Docker Compose
- **Análise de Código**: SonarQube
