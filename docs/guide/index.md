# API Find a Friend - Documentação

Bem-vindo à documentação da API Find a Friend, uma solução completa para conectar tutores e pets.

## 🎯 Sobre o Projeto

API RESTful desenvolvida em Node.js com TypeScript para gerenciamento de tutores e pets, seguindo princípios SOLID e boas práticas de desenvolvimento.
